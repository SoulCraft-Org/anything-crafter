# Guide: design

## What this route covers

A design, mockup or screenshot. You learn its grid, type, colour and components.

## What to look at

1. Open the design and note its size, the screen kind and what it is for.
2. Find the grid: columns, margins, gutters and the spacing steps.
3. List the type: each font, size and weight, and where it is used.
4. List the colours: background, text, accent, and the states (hover, error, success).
5. List the components: buttons, cards, inputs, menus, icons. Note their shapes and sizes.
6. Note the visual order: what the eye reads first, second and third.
7. Note what changes on other sizes, if more than one is shown.

## How to study it

| Case | Do |
| --- | --- |
| Default | Use a Figma tool if you have one. Read the frames, styles and variables |
| Fallback | Use vision on the image. Estimate sizes and colours, and mark each estimate Inferred |

A screenshot has no real tokens. Say so on the card.

## What to record on the study card

| Part | Write down |
| --- | --- |
| Grid | Columns, margins, spacing steps |
| Type | Fonts, sizes, weights, roles |
| Colour | A short list of colours with their roles |
| Components | Each component with its shape and states |
| Order | What reads first, second, third |
| Proof | The frame, layer or image area behind each claim |

Mark each line Seen, Inferred or Unknown.

## When to say no

Say no, and say why in one line, when:

- The design is private and you have no access. Never use someone else's token.
- You are asked to copy its art, logo, icons or brand name.
- You are asked to match it pixel for pixel. Learn the how, then design your own.
