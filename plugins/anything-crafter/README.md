# Anything Crafter

Show your AI examples. It learns how they are built, then builds your own.

```bash
claude plugin install anything-crafter --marketplace SoulCraft-Org/anything-crafter
```

Try it: "Build me a start page like these two, but mine: calm, one file, no account."

| Stage | Does |
| --- | --- |
| 🎯 Show | Your vision first, then 1 or more examples |
| 🔬 Study | How each example is built. Every claim is Seen, Inferred or Unknown |
| 🧩 Blend | A menu of parts across examples. ✋ You pick |
| 📐 Blueprint | Your original design. Every piece traces to your vision or a pick |
| 🔨 Craft | Builds it from the brief and blueprint only |
| ✅ Check | A fresh reviewer scores every promise with proof. ✋ You read the score |

Five rules: vision first, study before you build, evidence not guesses, learn the how and never copy the what, done means proven.

| Inside | |
| --- | --- |
| Skill | [`craft`](skills/craft/SKILL.md), with 6 guides: website, web app, code, doc and deck, design, app and binary |
| Agent | [`checker`](agents/checker.md), the fresh reviewer for the Check stage |

It says no to copying names, logos, text, code or locks, then offers an original. It works in Claude Code and any AI that reads Agent Skills.
