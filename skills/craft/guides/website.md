# Guide: website

## What this route covers

A public website you can open without an account. You learn its pages, layout, content structure, navigation and styling patterns.

## What to look at

1. Open the home page and note the page title and the main promise.
2. List every item in the main navigation and the footer.
3. Open 3 more pages of different kinds (for example a list, a detail page and a form page).
4. For each page kind, sketch the layout from top to bottom as a list of sections.
5. Note how the content is grouped: headings, cards, lists, tables.
6. Note the styling: colours, fonts, spacing, buttons, and how it looks on a narrow screen.
7. Open the page source (view-source) and note the headings, the meta tags and the main style files.

## How to study it

| Case | Do |
| --- | --- |
| Default | Use a browser tool if you have one. Open each page, read it and look at a screenshot |
| Fallback | Fetch each page as text, then read its source. Say that you could not see it drawn |

Never log in, sign up or fill in a form.

## What to record on the study card

| Part | Write down |
| --- | --- |
| Pages | Each page and what it is for |
| Layout | Sections from top to bottom, per page kind |
| Content | How content is grouped, and in what order |
| Navigation | Menu items, footer links, how a visitor moves |
| Styling | Colours, fonts, spacing, button shapes, narrow-screen changes |
| Proof | The page address or source line behind each claim |

Mark each line Seen, Inferred or Unknown.

## When to say no

Say no, and say why in one line, when:

- The site needs a login, a paywall or an invite. Study only what is public.
- You are asked to copy its words, images, logo or brand name.
- You are asked to scrape it in bulk, or to get around a block or a robots rule.
