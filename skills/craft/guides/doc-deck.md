# Guide: doc and deck

## What this route covers

A document, slide deck, PDF or sheet. You learn its structure, sections, layout and visual system.

## What to look at

1. Open the file and note the title, the length and the audience.
2. List every section or slide title in order. This is the outline.
3. For each type of page, note the layout: columns, headings, image and text positions.
4. Note how long each section is, and how it opens and closes.
5. Note the visual system: fonts, sizes, colours, spacing, and repeated elements such as headers and footers.
6. For a sheet, list the tabs, the columns, the formulas and the totals.
7. Note the tone of the words (not the words themselves).

## How to study it

| Case | Do |
| --- | --- |
| Default | Read the file with a file reader. For a PDF or deck, also look at each page as an image |
| Fallback | Read the extracted text only, or ask the person for page images. Mark layout claims Unknown if you saw no image |

## What to record on the study card

| Part | Write down |
| --- | --- |
| Outline | Section or slide titles in order |
| Layout | Page kinds and how each is arranged |
| Visual system | Fonts, colours, spacing, repeated elements |
| Sheet parts | Tabs, columns, key formulas |
| Tone | Plain, formal or playful, in a few words |
| Proof | The page, slide or cell behind each claim |

Mark each line Seen, Inferred or Unknown.

## When to say no

Say no, and say why in one line, when:

- The file is locked or encrypted and you were not given the key.
- You are asked to copy its text, images or logo. Learn the how, never copy the what.
- It holds personal data. Never write names, numbers or addresses on the card.
